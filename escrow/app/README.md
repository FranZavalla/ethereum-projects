# Escrow app

React frontend for [`contracts/Escrow.sol`](../contracts/Escrow.sol), scaffolded with Vite and
TypeScript. It talks to MetaMask through `window.ethereum` — no keys are handled here, all
transactions are signed in the wallet.

## Prerequisites

Start a local chain from the project root:

```shell
npm run localnet          # hardhat node on http://127.0.0.1:8545, chain id 31337
```

Add a network to MetaMask pointing at `http://127.0.0.1:8545` with chain id `31337` (the app's
"Switch to Hardhat Local" button will offer to add it for you). Then import one of the accounts
`hardhat node` prints on startup so you have ETH to deploy with.

## Usage

```shell
npm install
npm run dev
```

| Script | What it does |
| --- | --- |
| `npm run dev` | Vite dev server with HMR |
| `npm run build` | Type-check and build to `dist/` |
| `npm run preview` | Serve the production build |
| `npm run lint` | oxlint |
| `npm run sync:abi` | Refresh `src/contracts/Escrow.json` from the compiled artifact |

`dev` and `build` run `sync:abi` first, so the app always uses the same ABI and bytecode as the
contract you last compiled in the project root. If the artifact is missing the committed copy is
left in place.

## Configuration

Copy `.env.example` to `.env` to prefill the contract address:

```shell
VITE_ESCROW_ADDRESS=0x...
```

Leave it empty and paste an address into the page instead — or deploy one from the page itself.

## What the page does

- **Connect** — connects MetaMask, shows the account, its balance, and the current chain.
- **Escrow contract** — reads `depositor`, `arbiter`, `beneficiary`, `isApproved` and the contract
  balance for an address. The role you are signed in as is tagged `you`.
- **Release** — calls `approve()`, enabled only when the connected account is the arbiter and the
  funds are still held. The contract sends its entire balance to the beneficiary.
- **Create an escrow** — deploys a new `Escrow` (arbiter, beneficiary, deposit) and loads it into
  the panel. This is the only way to put funds into an escrow: the constructor is `payable` and
  sets `depositor` to `msg.sender`, and the contract has no deposit function.

## Layout

```
src/
  contracts/Escrow.json   generated by the sync:abi script
  hooks/
    useWallet.ts          MetaMask account, chain and balance
    useEscrow.ts          reads a deployed Escrow, calls approve()
    useDeployEscrow.ts    deploys a new Escrow
  lib/ethereum.ts         provider access, chain switching, formatting
  components/             WalletBar, EscrowPanel, CreateEscrowForm
```

One detail worth knowing: after a transaction the app re-reads the contract pinned to the block
the transaction was mined in. Reading `latest` immediately after a send can still resolve to the
previous block, which shows a half-updated view — "released", but with the old balance.
